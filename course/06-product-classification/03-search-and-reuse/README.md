# Параметрический поиск, аналоги и повторное использование

[К теме «Классификация изделий и компонентная база»](../README.md)

## Основная идея

Поиск кандидата и разрешение применения — разные решения. Параметрический поиск отвечает, какие объекты удовлетворяют заданным признакам; инженерная оценка — пригодны ли они в конкретном контексте.

## Сопоставление

Сначала нормализуют единицы и проверяют полноту характеристик. Затем сравнивают геометрию, интерфейсы, режимы, статус жизненного цикла и подтверждения. Пороговые требования и предпочтения имеют разный вес: меньшая масса не компенсирует недопустимый разъём.

## Пример

Найденный насос обеспечивает нужную подачу, но требует другое питание. Он может стать кандидатом на изменение подсистемы, однако не непосредственной заменой в текущем составе. Решение о повторном использовании фиксируют связью с контекстом и основанием, чтобы следующий пользователь не принял похожесть за утверждённую эквивалентность.

## Отбор, ранжирование и допуск

Отбор исключает кандидатов, нарушающих обязательные условия. Ранжирование упорядочивает оставшихся по предпочтениям: массе, доступности или унификации. Допуск разрешает применение в заданном изделии. Это три разных решения. Хороший результат по предпочтениям не компенсирует нарушение обязательного интерфейса.

Сравнение должно показывать основание: какие значения известны, какие нормализованы и где использовалось предположение. Если диапазон компонента перекрывает лишь часть требуемого диапазона, совпадение одного номинального значения не подтверждает пригодность.

## Повторное использование знания

Прежний допуск аналога полезен как источник решения, но его область может быть уже нового применения. Например, одобрение для наземного стенда не определяет пригодность для другого контекста. Повторно используют идентичности и доказательства с их границами. Результат нового рассмотрения связывается с новым контекстом, не расширяя молча первоначальное разрешение.
