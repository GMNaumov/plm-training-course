# 01. Основы PLM/PDM и жизненный цикл изделия

[К программе курса](../README.md)

## О теме

PLM — управление жизненным циклом изделия: согласованное управление его определением, изменениями и связанными решениями от замысла до вывода из эксплуатации. PDM — управление данными об изделии, прежде всего составами, документами, файлами и их версиями. Граница между ними в программных продуктах различается; в курсе PDM рассматривается как фундамент инженерных данных внутри более широкого подхода PLM.
