# Цифровая нить и связи инженерных данных

[К теме «Основы PLM/PDM и жизненный цикл изделия»](../README.md)

## Основная идея

Цифровая нить — прослеживаемая связь инженерных решений и свидетельств на протяжении жизненного цикла. Она строится из идентифицируемых объектов и типизированных отношений.

## Семантика связей

Отношения «удовлетворяет требованию», «входит в состав», «изготовлено по» и «подтверждено протоколом» имеют разные значения. Для каждого нужны направление, допустимые типы концов, версия источника и область действия. Ссылка на текущий документ не заменяет ссылку на ревизию, по которой проводилось испытание.

## Пример

Требование к температурному диапазону связано с датчиком, его расчётным обоснованием и протоколом испытания. Экземпляр датчика связан с партией и установкой на двигатель. При изменении требования сеть помогает найти кандидатов для анализа. Наличие пути в графе показывает связь, но пригодность доказательства оценивают с учётом испытанной конфигурации.

## Прослеживаемость как цепочка утверждений

Каждое ребро цифровой нити можно прочитать предложением: «эта ревизия реализует такое требование», «этот протокол проверяет такую характеристику», «этот экземпляр изготовлен по такому определению». Если предложение невозможно сформулировать однозначно, связь слишком общая для надёжного вывода.

Например, связь документа с блоком управления может означать инструкцию обслуживания, исходный расчёт или протокол испытания. По одной универсальной метке «связан с» нельзя определить, какой документ надо пересмотреть после изменения питания. Типизация отношений уменьшает неоднозначность анализа.

## Достоверность и полнота сети

Связь может существовать, но вести к неподходящей ревизии либо не охватывать нужные условия. Напротив, отсутствие связи иногда означает незаполненную модель. Поэтому цифровая нить даёт основание обнаруживать и объяснять зависимости, а не автоматически принимать инженерные решения. Для важных переходов сохраняют источник связи, её владельца и результат оценки пригодности. Так сеть становится проверяемой историей утверждений.
