# Материалы, стандартные и покупные компоненты

[К теме «Нормативно-справочная информация»](../README.md)

## Основная идея

Материал, стандартная деталь и покупной компонент требуют разных сведений. Для материала значимы спецификация и состояние поставки; для стандартного крепежа — типоразмер и исполнение; для покупного блока — идентификатор изготовителя, разрешённые исполнения и условия применения.

## Идентификация

Внутреннее обозначение предприятия может связываться с несколькими поставщиками, но их изделия становятся допустимыми источниками только после принятого решения. Обозначение производителя и каталожный номер уникальны в своей области, а не обязательно во всём мире.

## Граница замены

Два датчика с одинаковым диапазоном измерения могут различаться разъёмом, протоколом или доказательствами квалификации. Список одобренных источников закупки не равен безусловной взаимозаменяемости. Разрешение замены фиксируется с контекстом, ограничениями и основанием.
