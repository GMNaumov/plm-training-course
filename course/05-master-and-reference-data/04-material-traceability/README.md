# Прослеживаемость материалов, партий и подтверждающих документов

[К теме НСИ](../README.md)

## Основная идея

Прослеживаемость материала связывает проектное требование с фактически использованным источником. Плавка, партия поставки и производственная партия могут быть разными объектами с отношениями происхождения.

## Модель генеалогии

Разделение партии создаёт несколько потомков; объединение — потомка с несколькими источниками. Количества и единицы учитывают отдельно от идентичности. Подтверждающий документ имеет издателя, дату, охватываемые партии и результаты проверки. При преобразовании материала сохраняют связь с исходным состоянием.

## Пример

Две заготовки из одной плавки проходят разные режимы обработки. Их происхождение общее, но производственная история различается. Если обнаружена проблема плавки, анализ охватывает обе; если проблема режима — соответствующую ветвь. Хранение номера сертификата одной строкой без связей не позволяет надёжно различить эти случаи.

## Баланс происхождения при преобразовании

Материальная генеалогия должна объяснять, какие входы дали какой результат. При разделении партии суммы выходных количеств сопоставляют с исходным количеством с учётом явно зарегистрированного расхода и потерь. Для преобразований с изменением единиц нужна отдельная модель выхода; механическое равенство чисел здесь бессмысленно.

Документ может покрывать всю партию, часть поставки либо конкретный результат контроля. Связь только с поставщиком не определяет покрытие. При исправлении документа сохраняют, какой выпуск был принят ранее и требуется ли пересмотр решения о приёмке.

## Граница расследования

Проблема исходного материала распространяется через отношения происхождения. Проблема отдельной операции — через записи её исполнения. Если хранить только общий номер производственной партии, эти области смешаются. Надёжная модель позволяет проследить обе цепочки и определить, где происхождение известно точно, а где остаётся неопределённость. Последняя влияет на область рассмотрения и не устраняется предположением о наиболее вероятном источнике.
