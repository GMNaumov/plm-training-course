# Справочники, единицы измерения и нормализация значений

[К теме «Нормативно-справочная информация»](../README.md)

## Основная идея

Справочник ограничивает допустимые значения и обеспечивает общий смысл. Код хранит устойчивую идентичность, отображаемое название помогает человеку. Перевод или исправление названия не должно менять ссылки.

## Значения и размерности

Единица относится к определённой величине. Число без единицы неоднозначно; число без условий измерения иногда недостаточно. Для температуры важно различать абсолютное значение и разность температур: правила преобразования отличаются. Точность представления не равна допуску на изделие.

## Пример

Диаметр 12 мм и 0,012 м представляют одну величину. Значение «12» в строковом поле этого не гарантирует. Для номинала, нижнего и верхнего пределов задают отдельный смысл. Нормализация нужна не только для поиска: без неё сравнение характеристик и агрегирование дают внешне правдоподобный, но неверный результат.

## Единица, база и округление

Количество «5» может означать пять штук, пять метров либо пять килограммов. Кроме единицы нужна база: на один узел, на партию или на операцию. Сравнение норм с разной базой не становится корректным после одного пересчёта единиц.

Округление зависит от назначения. Инженерная длина провода может храниться с достаточной точностью, а закупочная потребность округляться до упаковки. Если округлить каждое вхождение до бухты до агрегирования, итог будет отличаться от округления общей закупки. Оба вычисления имеют смысл только при явно поставленном вопросе.

## Пропуски в измеримых свойствах

Нулевое значение — известное число. Неизвестное значение означает отсутствие знания. Неприменимость означает отсутствие самой характеристики у объекта. Отдельно может существовать предел обнаружения измерения. Сведение всех случаев к пустой строке делает фильтры и показатели качества неоднозначными. Тип и статус значения должны сохранять различие факта, требования и отсутствия данных.
