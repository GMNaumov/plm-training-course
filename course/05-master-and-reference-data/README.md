# 05. Нормативно-справочная информация

[К программе курса](../README.md)

## О теме

Нормативно-справочная информация (НСИ) задаёт общий язык инженерных данных: материалы, единицы, обозначения, организации и разрешённые значения. После темы читатель понимает различие справочника, мастер-данных и транзакционного факта; может объяснить, почему одинаковое написание ещё не означает тождество объектов.
