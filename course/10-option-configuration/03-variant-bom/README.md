# Вариантный состав: 150-процентное и 100-процентное представления

[К теме «Конфигурирование по опциям и вариантам»](../README.md)

## Основная идея

150-процентный состав описывает возможные компоненты семейства с условиями участия. 100-процентный отражает выбранное исполнение. Это термины вариантного моделирования, а не измерение количества деталей.

## Условия включения

Условие относится к вхождению: одна деталь может использоваться безусловно в одном месте и условно в другом. В альтернативной группе правило определяет, сколько ветвей включается. Отсутствие выбранной ветви может означать допустимую опцию «без компонента» либо дефект полноты — эти случаи различают.

## Пример

Два исполнения жгута занимают одну функциональную позицию. Выбор интерфейса включает только подходящее вхождение. Исключение строк по тексту названия компонента не обеспечивает этой семантики. Полученный состав дополнительно разрешают по ревизиям, проверяют на циклы и полноту связанной документации.
