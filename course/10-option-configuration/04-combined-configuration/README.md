# Совместное применение опций, ревизионных правил и применяемости

[К теме «Конфигурирование по опциям и вариантам»](../README.md)

## Основная идея

Опции отвечают, какие решения нужны, применяемость — где они действуют, ревизионные правила — какое определение выбрать. Каждое измерение сохраняет собственный смысл.

## Контекст результата

Для воспроизводимости фиксируют корневое определение, выбор признаков, дату или серию, версию правил и выбранные зависимости. Ключ кэша или отчёта, содержащий только набор опций, может смешать разные инженерные конфигурации.

## Пример

Вариант с резервированием разрешён правилами семейства, но новая ревизия блока выпущена только для поздней серии. Для раннего экземпляра такой выбор может оказаться неразрешимым. Нельзя автоматически брать рабочую ревизию или отключать ограничение применяемости. Корректный результат — объяснимое отсутствие допустимого определения с указанием конфликтующего условия.
