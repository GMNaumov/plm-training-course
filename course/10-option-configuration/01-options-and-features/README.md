# Семейства изделий, признаки, опции и значения

[К теме «Конфигурирование по опциям и вариантам»](../README.md)

## Основная идея

Семейство объединяет изделия с общими решениями и управляемыми различиями. Признак описывает изменяемое свойство, домен — множество допустимых значений, выбор — конфигурацию конкретного запроса.

## Полнота выбора

Для обязательного признака должно быть задано значение. Множественный выбор требует ограничений количества и совместимости. Значение по умолчанию — правило заполнения, а не доказательство пригодности. Незаданный параметр полезен в предварительном поиске, но не всегда допустим при выпуске.

## Пример

Признак «каналы управления» принимает значения «один» и «два». Признак «комплект датчиков» зависит от него. Отдельные коммерческие названия исполнений можно связать с набором признаков; копирование названий в каждую позицию состава делает общую модель вариантов трудно проверяемой.
