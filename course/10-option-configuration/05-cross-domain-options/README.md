# Междисциплинарные варианты механики, электрики, электроники и ПО

[К теме конфигурирования по опциям](../README.md)

## Основная идея

Вариант изделия пересекает границы механики, электрики, электроники и ПО. Общий признак должен согласованно изменять все связанные определения и интерфейсы.

## Интерфейсные зависимости

Совместимость включает геометрическое сопряжение, питание, распиновку, протокол, функции и разрешённые версии ПО. Связи совместимости версионируют; общее имя семейства не подтверждает сочетание конкретных ревизий.

## Пример

Дополнительный канал измерения требует места крепления, датчика, контактов жгута, входа блока и поддержки прошивкой. Каждый компонент может быть выпущен отдельно, но комплект — ещё не подтверждён. Поэтому совместимость оценивают для конфигурации и связывают с результатами проверок. При изменении одного интерфейса анализ охватывает всех его участников.
