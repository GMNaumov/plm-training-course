# Постановка задачи и модель данных изделия

[К теме «Итоговый сквозной проект»](../README.md)

## Основная идея

Постановка PLM-задачи начинается с вопроса предприятия и границ ответственности. Сначала определяют, какие решения и факты должны быть управляемыми, затем выбирают объекты и механизмы.

## Целостность модели

Модель связывает идентичности изделий, ревизии, вхождения, документы, процессы, экземпляры и свидетельства. У каждого факта есть владелец, временной смысл и источник. У каждого отношения — назначение и ограничения. Необязательно помещать все области в одну систему, но границы обмена должны быть явными.

## Границы этапа

Сквозной контекст авиационного двигателестроения уже определён. Точный перечень узлов и обязательные атрибуты пока не утверждены. Настоящая практическая постановка должна будет закрепить эти решения; этот раздел объясняет подход и не задаёт будущему учащемуся задания или скрытого эталонного решения.
