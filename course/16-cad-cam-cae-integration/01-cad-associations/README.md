# Связи CAD-моделей, чертежей и объектов изделия

[К теме «Интеграция с CAD/CAM/CAE»](../README.md)

## Основная идея

Объект изделия, CAD-модель и чертёж имеют связанные, но самостоятельные идентичности. Модель может задавать геометрию, чертёж — дополнительные требования и представления.

## Роли связей

Различают определяющую модель, справочную геометрию, чертёж и производное представление. Правило соответствия версий задаётся явно: одинаковая буква ревизии в двух системах не гарантирует согласованность. Для общих моделей и семейств возможны связи не один-к-одному.

## Пример

Один исходный шаблон создаёт несколько исполнений деталей. Каждое исполнение имеет собственное управляемое определение, хотя часть авторских зависимостей общая. При изменении шаблона оценивают все полученные исполнения. Простая ссылка на файл без роли и версии не объясняет, какая геометрия определяет выпущенное изделие.

## Однозначность определяющей роли

Если у изделия несколько моделей, должно быть понятно, какая из них определяет конкретное исполнение и какие служат справке. Для одной дисциплины может действовать одна основная модель, для другой — отдельная схема. Универсальное требование «ровно один файл на изделие» не соответствует такой многодисциплинарности.

Чертёж может добавлять требования, отсутствующие в геометрии. Поэтому удаление связи с ним после появления модели требует предметной политики, а не предположения, что вся информация уже перенесена в 3D.

## Зависимые исполнения

Семейство моделей может порождать несколько деталей с общими исходными зависимостями. Изменение общего источника формирует кандидатов для пересмотра, но не означает автоматического перевыпуска всех изделий. У каждого исполнения своя область определения и подтверждения. Согласованная связь указывает, какой результат авторской системы соответствует какому управляемому определению PLM и в каком состоянии.
