# CAM-проекты, управляющие программы и производственный контекст

[К теме «Интеграция с CAD/CAM/CAE»](../README.md)

## Основная идея

CAM-проект организует подготовку обработки; управляющая программа предназначена для определённого оборудования и конфигурации исполнения. Это разные управляемые результаты.

## Зависимости

Программа связана с геометрией детали, заготовкой, установом, оснасткой, инструментом и постпроцессором. Постпроцессор преобразует подготовленные траектории в целевой формат; его версия влияет на происхождение результата. Проверка и разрешение применения фиксируются отдельно от генерации.

## Пример

Перенос программы на другой станок нельзя считать допустимым только из-за одинакового расширения файла. Изменение оснастки также может потребовать пересмотра. Факт исполнения связывается с точной разрешённой программой. Учебный курс описывает управление этими зависимостями, без разработки реальных траекторий и режимов обработки.
