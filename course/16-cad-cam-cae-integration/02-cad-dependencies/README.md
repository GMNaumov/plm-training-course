# Зависимости CAD-сборок, метаданные и синхронизация EBOM

[К теме «Интеграция с CAD/CAM/CAE»](../README.md)

## Основная идея

CAD-сборка зависит от версий компонентов, внешних ссылок и настроек загрузки. Сохранить главный файл недостаточно, если остальные зависимости остаются плавающими.

## Синхронизация EBOM

Преобразование CAD-структуры требует правил включения: вспомогательная геометрия может исключаться, а негеометрические компоненты — добавляться из других источников. Количество, размещение и свойства передаются с известным владельцем. Обратные изменения требуют обработки конфликтов.

## Пример

Инженер перестроил CAD-сборку, а технологически значимое обозначение изменилось в PLM. Адаптер не должен выбирать победителя только по последней дате файла. Сначала определяют, где управляется каждый факт. Проверка сохранения охватывает полный набор зависимостей и сообщает, какие элементы не удалось зафиксировать или сопоставить.
