# Расчётные модели, условия, результаты и прослеживаемость CAE

[К теме «Интеграция с CAD/CAM/CAE»](../README.md)

## Основная идея

CAE-результат имеет смысл только вместе с расчётной постановкой. Цветная карта без исходной конфигурации и условий не является воспроизводимым обоснованием.

## Происхождение

Сохраняют связи с ревизией геометрии, принятыми упрощениями, материалами, сеткой, нагрузками, граничными условиями, инструментом и исходными параметрами решения. Методическая проверка модели и инженерная интерпретация результата имеют свои основания.

## Пример

После изменения корпуса прежний результат может остаться консервативным либо потерять применимость. Сам факт новой ревизии не позволяет решить это автоматически. Система отмечает зависимость для оценки и сохраняет заключение о пригодности. Расчёт для одной конфигурации не переносится на все варианты только потому, что они принадлежат одному семейству.
