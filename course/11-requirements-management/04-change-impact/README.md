# Изменение требований и анализ затронутых объектов

[К теме «Управление требованиями»](../README.md)

## Основная идея

Изменение требования распространяется через связи на решения и свидетельства. Анализ определяет кандидатов на пересмотр; окончательное решение принимает ответственный специалист.

## Типы влияния

Ужесточение предела может потребовать нового испытания, изменение формулировки — только уточнения смысла, перенос применяемости — оценки затронутых экземпляров. Поэтому изменение текста не следует автоматически считать ни существенным, ни несущественным.

## Сохранение решения

Для каждой затронутой связи фиксируют оценку: остаётся пригодной, требует пересмотра или заменена. Прежние заключения не удаляют. Если новое требование действует только для поздней серии, свидетельства по ранней сохраняют свой контекст. Отсутствие связи в модели не доказывает отсутствия реального влияния: полнота прослеживаемости сама подлежит оценке.

## Семантическая разница между пересмотрами

Изменение опечатки и изменение диапазона могут давать одинаковый текстовый объём правки, но разное влияние. Поэтому анализ начинается с классификации изменившегося смысла: объект, характеристика, условие, предел, метод или применяемость.

Далее рассматриваются реализации и свидетельства. Прежний расчёт может сохранять пригодность с новым обоснованием; испытание может требовать повторения; документ может нуждаться только в новой ссылке. Решение принимается по содержанию, а не исключительно по факту новой ревизии.

## Подозрительная связь

При изменении источника связь полезно помечать требующей оценки. Такая пометка означает неопределённую актуальность, а не автоматический отказ конструкции. После рассмотрения сохраняют результат и основание. Если пометки снимаются массово без анализа, механизм перестаёт выполнять задачу; если всё всегда признаётся недействительным, теряется возможность обоснованного повторного использования знания.
