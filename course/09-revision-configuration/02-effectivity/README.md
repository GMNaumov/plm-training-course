# Применяемость по дате, серийному номеру и партии

[К теме «Конфигурирование по ревизионным правилам»](../README.md)

## Основная идея

Применяемость, effectivity, описывает область действия определения или отношения. Это может быть дата, диапазон экземпляров, партия либо их комбинация.

## Границы и сочетание

В курсе для дат удобно явно задавать полуоткрытые интервалы: начало включается, конец исключается. Это учебное соглашение, не универсальное поведение PLM. Для дискретных номеров применяют явно описанные включительные границы и область серии. Несколько измерений можно сочетать через «и» или «или», но выбор должен быть задан правилом.

## Граничные ситуации

Отсутствие значения контекста не равно разрешению на всё. Если для выбора нужна партия, а она неизвестна, результат остаётся неопределённым. Перекрытие диапазонов требует приоритета либо ошибки; разрыв — сообщения о невозможности разрешения. Универсальная дата изменения записи не заменяет дату начала применения.

## Пустая граница и неизвестный контекст

Отсутствующая верхняя граница интервала может означать отсутствие установленного конца. Отсутствующая дата самого запроса означает неизвестный момент применения. Это разные случаи. Первое описывает область определения, второе — неполный вход вычисления.

Для серийного диапазона сначала устанавливают семейство или систему нумерации. Номера разных изготовителей нельзя сравнивать как одну последовательность. Лексикографический порядок строк также может отличаться от принятого порядка серий.

## Перекрытие в нескольких измерениях

Ревизия может действовать с определённой даты и только для части серий. Тогда нужно знать, применяются ли условия совместно. Если дата подходит, а серия нет, результат зависит от заданной логики, а не от количества совпавших полей. Два диапазона, не пересекающиеся по дате, не обязательно конфликтуют из-за одинаковых серий; анализируется полная область. Такие правила должны быть понятны пользователю до выбора конфигурации.
