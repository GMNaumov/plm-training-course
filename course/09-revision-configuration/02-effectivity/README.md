# Применяемость по дате, серийному номеру и партии

[К теме «Конфигурирование по ревизионным правилам»](../README.md)

## Основная идея

Применяемость, effectivity, описывает область действия определения или отношения. Это может быть дата, диапазон экземпляров, партия либо их комбинация.

## Границы и сочетание

В курсе для дат удобно явно задавать полуоткрытые интервалы: начало включается, конец исключается. Это учебное соглашение, не универсальное поведение PLM. Для дискретных номеров применяют явно описанные включительные границы и область серии. Несколько измерений можно сочетать через «и» или «или», но выбор должен быть задан правилом.

## Граничные ситуации

Отсутствие значения контекста не равно разрешению на всё. Если для выбора нужна партия, а она неизвестна, результат остаётся неопределённым. Перекрытие диапазонов требует приоритета либо ошибки; разрыв — сообщения о невозможности разрешения. Универсальная дата изменения записи не заменяет дату начала применения.
