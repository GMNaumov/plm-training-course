# Сквозной анализ влияния изменений

[К теме «Сквозная прослеживаемость и инженерная аналитика»](../README.md)

## Основная идея

Сквозной анализ влияния рассматривает проектные, производственные и фактические последствия изменения. Он состоит из обнаружения связей и оценки их инженерной значимости.

## Ограничение области

Учитывают конкретные ревизии, опции, применяемость и историю установок. Несколько путей к одному объекту могут давать разные основания затрагивания; их полезно сохранять, даже если итоговый список объектов устранит дубли.

## Пример

Новая прошивка нужна не всем блокам семейства, а сочетанию аппаратной ревизии и конкретной функции. Поиск всех применений модели блока даст избыточную популяцию. Исключение по текущей типовой конфигурации, напротив, может пропустить ранее доработанные экземпляры. Область решения формируется по фактам и сохраняется вместе с причинами включения и исключения.

## Потенциальное влияние и назначенное действие

Обнаруженный путь означает необходимость рассмотреть объект. После оценки может быть назначено изменение, подтверждена пригодность прежнего решения либо установлена неприменимость. Итоговый список действий поэтому обычно уже множества кандидатов, но причины исключения должны оставаться доступными.

Область анализа может включать складские компоненты, незавершённые партии, поставленные изделия и демонтированные узлы. Текущий физический состав покрывает только часть этой области.

## Сохранение объяснения

Для каждого включённого объекта полезно знать исходную проблему, значимые пути, применённые фильтры и принятое заключение. Если модель позже изменится, прежний анализ должен оставаться интерпретируемым. Повторный обход по новым данным может дать другой результат и является новым срезом. Изменение списка не обязательно означает ошибку: могли уточниться факты установки или происхождения, и это различие нужно объяснить.
