# Настройка жизненных циклов и процессов согласования

[К теме «Администрирование, модель доступа и расширение системы»](../README.md)

## Основная идея

Жизненный цикл определяет состояния и переходы. Поток согласования организует задачи, решения и исполнение переходов. Один цикл может использовать несколько процессов для разных документов.

## Настраиваемые правила

Переход имеет исходное состояние, условие, полномочие и результат. Задача — исполнителя, входные материалы и варианты решения. Автоматический обработчик проверяет те же предметные ограничения, что и ручное действие.

## Пример

Выпуск расчёта требует проверенного набора исходных данных и одобрения расчётчика. Завершение задач не гарантирует условий, если исходная модель изменилась. Перед переходом повторно проверяют версии и полноту. При отказе сохраняют причину и маршрут возврата, а не стирают историю решений.
