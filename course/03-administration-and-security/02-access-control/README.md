# Права доступа, наследование и проверка полномочий

[К теме «Администрирование, модель доступа и расширение системы»](../README.md)

## Основная идея

Разрешение вычисляется для действия над объектом с учётом субъекта и контекста. Чтение метаданных, просмотр представления, скачивание исходника, изменение состава и выпуск ревизии — разные действия.

## Наследование и проверка

ACL задаёт правила доступа к объектам, RBAC — разрешения ролей, ABAC — условия на атрибуты. Они могут сочетаться. Приоритет запрета не переносится между продуктами без проверки. Исходный принцип курса — разрешать только предусмотренные действия.

## Граничный случай

Пользователь видит сборку, но не имеет прав на компонент. Система должна сохранять безопасность и сообщать о неполноте в допустимой форме. Скрытый объект нельзя молча интерпретировать как отсутствующий в составе. Те же правила действуют для отчётов, API и публикации файлов.
