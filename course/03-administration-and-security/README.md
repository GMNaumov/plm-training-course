# 03. Администрирование, модель доступа и расширение системы

[К программе курса](../README.md)

## О теме

Администрирование включает управление идентичностями, доступом, типами объектов, жизненными циклами и переносом настроек. После темы читатель понимает, как конфигурация системы поддерживает предметные правила и почему изменения настроек должны быть управляемыми.
