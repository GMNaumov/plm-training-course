# Согласование составов и перенос инженерных изменений

[К теме «Производственный состав изделия: MBOM»](../README.md)

## Основная идея

Reconciliation — согласование связанных представлений и их изменений. Различие структур ожидаемо; задача состоит в объяснении покрытия, добавлений, исключений и устаревших связей.

## Смысл расхождений

Изменение количества может потребовать обновить норму; перенос позиции — только связь размещения; новая ревизия — оценить интерфейсы и процесс. Инженерное удаление не означает автоматического удаления всех производственных материалов и операций.

## Пример

В EBOM заменён разъём. MBOM содержит соответствующий разъём и технологическую заглушку для испытаний. Автоматический перенос первой строки полезен, но пригодность заглушки требует оценки технолога. Результат согласования фиксирует решение по каждому значимому расхождению и контекст новой производственной конфигурации.

## Три исхода сравнения

Расхождение может требовать изменения MBOM, не требовать его по обоснованной причине либо оставаться на рассмотрении. Последний исход важен: отсутствие готового решения не должно выглядеть подтверждённой согласованностью.

Например, изменилось обозначение документа без изменения компонента — производственная структура может сохраниться, но пакет инструкции требует оценки. Изменилось количество инженерного крепежа — нужно проверить покрытие, расход и соответствующие операции. Удаление ветви требует рассмотреть связанные производственные добавления, а не удалять их все автоматически.

## Сохранение основания

Для принятого результата указывают исходную и целевую конфигурации, область площадки и решение по значимым различиям. Тогда следующий пересмотр сравнивается с определённым состоянием, а не с неопределённой «последней синхронизацией». Если часть расхождений принята как допустимая особенность производства, эта причина остаётся доступной и не создаёт повторную ложную ошибку при каждом анализе.
