# Версии техпроцессов, применяемость и согласованность с MBOM

[К теме «Технологические процессы и производственные маршруты»](../README.md)

## Основная идея

Изменение процесса связано с исходным составом, ресурсами и областью действия. Версия инструкции без согласованной версии операции не даёт полного производственного определения.

## Согласованность

Фиксируют используемую MBOM, ревизию процесса, распределение материалов и необходимые ресурсы. Изменение может вступать в силу для новых партий, отдельных экземпляров или площадки. Для незавершённого производства определяют допустимый переход либо завершение по прежнему решению.

## Пример

После изменения покрытия нужна новая подготовительная операция и иной контроль. Обновление только названия покрытия оставляет маршрут неполным. Управление изменением охватывает инструкции, оснащение и свидетельства; история ранее выполненных работ сохраняется. Совместимость старого и нового определения оценивается по предметному смыслу, а не по совпадению номера процесса.
