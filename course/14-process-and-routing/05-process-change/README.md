# Версии техпроцессов, применяемость и согласованность с MBOM

[К теме «Технологические процессы и производственные маршруты»](../README.md)

## Основная идея

Изменение процесса связано с исходным составом, ресурсами и областью действия. Версия инструкции без согласованной версии операции не даёт полного производственного определения.

## Согласованность

Фиксируют используемую MBOM, ревизию процесса, распределение материалов и необходимые ресурсы. Изменение может вступать в силу для новых партий, отдельных экземпляров или площадки. Для незавершённого производства определяют допустимый переход либо завершение по прежнему решению.

## Пример

После изменения покрытия нужна новая подготовительная операция и иной контроль. Обновление только названия покрытия оставляет маршрут неполным. Управление изменением охватывает инструкции, оснащение и свидетельства; история ранее выполненных работ сохраняется. Совместимость старого и нового определения оценивается по предметному смыслу, а не по совпадению номера процесса.

## Совместимый комплект определений

Производственный комплект включает MBOM, процесс, распределение компонентов, инструкции и ограничения ресурсов. Если обновить один элемент, остальные могут оставаться формально выпущенными, но уже не образовывать согласованного решения.

Например, новая ревизия детали требует другой оснастки. Состав MBOM обновлён, а операция продолжает ссылаться на прежнюю. Проверка только количества компонентов не обнаружит проблему. Нужны отношения происхождения и совместимости между определениями.

## Момент вступления изменения

Для новой партии может применяться новый процесс, а начатая завершаться по старому. Если требуется переход, задают исходное состояние и необходимые дополнительные действия. Фактическую историю не переписывают новым процессом. При расследовании важно увидеть, какой комплект действовал и реально использовался, а не только какой считается текущим сегодня. Применяемость процесса становится частью объяснения производственного результата.
