# Привязка MBOM к операциям, последовательности и маршрутам

[К теме «Технологические процессы и производственные маршруты»](../README.md)

## Основная идея

Распределение MBOM по операциям показывает, где компонент потребляется, устанавливается или преобразуется. Оно связывает состав с ходом изготовления, сохраняя разные значения этих структур.

## Полнота распределения

Для значимого вхождения проверяют, предусмотрено ли его участие и не учтено ли количество дважды. Одно вхождение может потребляться частями на нескольких операциях при явных правилах. Материал, возвращаемый после временного использования, отличается от окончательно потреблённого.

## Пример

Крепёж устанавливается на сборке, защитная заглушка применяется на испытании и снимается. Одинаковая связь «используется» скроет различие. Последовательность операций должна учитывать готовность входов: две независимые ветви можно объединить только после получения нужных результатов, а не просто после совпадения номеров операций.
