# 07. Управление документами и файлами

[К программе курса](../README.md)

## О теме

Управляемый документ связывает содержание с идентичностью, ревизией, состоянием и назначением. После темы читатель различает документ, файл, набор данных и производное представление; понимает блокировки редактирования и контролируемую публикацию.
