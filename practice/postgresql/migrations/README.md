# Изменение схемы и загрузка данных

[К SQL](../README.md) · [L01: DDL](../../exercises/l01-identity/README.md) · [L04: свойства](../../exercises/l04-reference/README.md) · [L14: перенос](../../exercises/l14-migration/README.md)

Учебная БД создаётся полной воспроизводимой инициализацией [reset.sql](../schema/reset.sql), не цепочкой производственных миграций. L01/L04 содержат самостоятельное создание таблиц; повторный запуск эталонов требует reset. L14 переносит данные через staging, контролируя происхождение и конфликты; это другой смысл слова «миграция».

Версия правил mass-v1 сохраняется в staging и mapping. Для изменения правил нельзя молча перезаписывать исходное соответствие. Версионируемые DDL-обновления без потери пользовательских данных, online-изменение схемы и инструменты миграций здесь не реализуются.
