Все команды выполняются psql внутри db. Скрипт sql использует -X и ON_ERROR_STOP=1. В интерактивной транзакции после ожидаемого отказа выполните ROLLBACK; не продолжайте работу в аварийном состоянии. reset удаляет результаты упражнений в lab. Суперпользователь учебного стенда используется для DDL и изучения механизмов; коммерческие системы следует интегрировать через их поддерживаемые API.
