# Модель учебной базы

[К SQL](../README.md) · [L01](../../exercises/l01-identity/README.md) · [L05](../../exercises/l05-ebom/README.md)

[reset.sql](reset.sql) атомарно удаляет только lab, включает [model.sql](model.sql) и [seed.sql](../../datasets/seed.sql). psql разрешает `\ir` относительно включающего файла. Инициализация не зависит от первого старта тома и повторяема. Вспомогательная NOLOGIN-роль lab_reader создаётся в кластере, если отсутствует; это упрощение административной демонстрации.

| Группа | Таблицы/представления | Смысл |
| --- | --- | --- |
| Справочники | unit, item | Единицы со своей размерностью, идентичность изделия |
| Определение | revision, occurrence, baseline, base_tree | Ревизии, вхождения, точный выбор, обход BASE-01 |
| Подтверждения | document, requirement, evidence | Метаданные документов, цели и связи свидетельств |
| Изменение | change_order, change_action | Решение, области внедрения, состояние и lock_version |
| Производство | mline, mapping | Нормы на один корневой модуль и соответствие полным путям EBOM |
| Процесс | resource, operation, precedence, allocation | Ресурсы, операции, частичный порядок и распределение |
| Факт | lot, serial_unit, installation, software_load, compatibility | Партия, индивидуальные экземпляры, интервалы и аппаратно-программные сочетания |
| Обмен | outbox, inbox, erp_definition | Намерение отправителя, квитанция и эффект получателя |
| Перенос | migration_stage, migration_target, migration_map | Принятый источник, нормализованная цель и происхождение |

Ключи текстовые и короткие ради чтения, не промышленная система нумерации. FK occurrence(child_item,fixed_revision) не позволяет зафиксировать ревизию чужого изделия. Допускается NULL fixed_revision для плавающей ссылки, но учебный BASE-01 содержит точный выбор. Наличие FK не гарантирует отсутствие циклов, допустимость ревизий, полноту свидетельств, размерность свойств, отсутствие пересечений установок или готовность производства. Эти границы исследуются в заданиях.

BASE-01 и base_tree — исходный снимок для базового исполнения. Представление готово для независимости L10 от реализации L05; не читайте его определение до собственной попытки L05. Внешние файлы и реальные инженерные документы не поставляются; URI обозначают только условный объект.

Новые таблицы iteration и mass_property обучающийся создаёт в L01/L04. Схема хранит намеренно слабые места (например, источник документа не обязан совпадать с целью evidence), чтобы показать различие ссылочной и предметной целостности. Их нельзя считать проектом промышленной схемы.
