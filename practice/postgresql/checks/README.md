# Ручная диагностика SQL

[К SQL](../README.md) · [Правила самопроверки](../../checks/README.md)

Автоматических проверяющих SQL-скриптов и оценивания нет. Диагностические запросы входят в задания и эталоны: [L05 — пути/циклы](../../exercises/l05-ebom/README.md), [L06 — ноль/один/несколько кандидатов](../../exercises/l06-revision/README.md), [L10 — покрытие](../../exercises/l10-mbom/README.md), [L11 — маршрут](../../exercises/l11-routing/README.md), [L12 — интервалы](../../exercises/l12-physical/README.md), [L14 — происхождение](../../exercises/l14-migration/README.md).

Студент читает результаты и сопоставляет с предметным ожиданием. Успешное выполнение запроса не является положительным заключением: запрос может обнаружить проблему, а пустой результат может быть следствием неполноты данных или неправильного соединения.
