# Java: транзакции, конфигурации и интеграции

[К практике](../README.md) · [Среда](../environment/README.md) · [L13](../exercises/l13-integration/README.md) · [Эталон](../solutions/l13.md)

[EventConsumer.java](EventConsumer.java) предоставляет main и сигнатуру consume. Реализуйте метод, изучив JDBC Connection, PreparedStatement, commit и rollback. Контейнер использует JDK 25 LTS и pgJDBC, закреплённый [Dockerfile](Dockerfile). Запуск source-file позволяет обойтись без Maven/Gradle и без скомпилированных файлов на хосте.

Далее доступна [углублённая ветка J01–J12](advanced/README.md): 12 самостоятельных задач с заготовками, SQL-сценариями, отдельными эталонами и дополнительными исследованиями. Она использует ту же среду и не требует фреймворков. Предметная логика включает графы BOM и маршрутов, конкурентный выпуск изменений, доставку с арендой, временную историю, виртуальные потоки, файлы и потоковую аналитику.

Параметры подключения передаются через внутренние переменные среды Compose. Таблицы получателя находятся в lab рядом с исходной моделью только ради малого стенда; транзакция L13 не изменяет PLM-определения и outbox. Доставка представлена ручным CLI-вызовом. Реальный HTTP API и брокер не развёрнуты. В L13 рассматривается сбой перед фиксацией; J07 отдельно показывает разрыв после фиксации эффекта получателя до подтверждения отправителя.
