# Java: транзакционный потребитель

[К практике](../README.md) · [Среда](../environment/README.md) · [L13](../exercises/l13-integration/README.md) · [Эталон](../solutions/l13.md)

[EventConsumer.java](EventConsumer.java) предоставляет main и сигнатуру consume. Реализуйте метод, изучив JDBC Connection, PreparedStatement, commit и rollback. Контейнер использует JDK 25 LTS и pgJDBC, закреплённый [Dockerfile](Dockerfile). Запуск source-file позволяет обойтись без Maven/Gradle и без скомпилированных файлов на хосте.

Параметры подключения передаются через внутренние переменные среды Compose. Таблицы получателя находятся в lab рядом с исходной моделью только ради малого стенда; транзакция L13 не изменяет PLM-определения и outbox. Доставка представлена ручным CLI-вызовом. Реальный HTTP API, брокер и сетевые отказы не эмулируются; рассматриваются их предметные последствия через повтор, конфликт и искусственный сбой перед фиксацией.
