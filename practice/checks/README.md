# Самостоятельная проверка

[К практике](../README.md) · [Каталог заданий](../exercises/README.md) · [Правила оценки](../../docs/assessment.md) · [Теория проверки](../../course/20-verification-and-testing/theory.md)

Проверку выполняет сам обучающийся: запускает свою реализацию, рассматривает данные, сопоставляет с критериями задания, объясняет расхождения и после собственной попытки читает эталон. Автоматического оценивания, скрытых тестов, баллов и проходного порога нет. Разработческие проверки автора не являются механизмом сдачи.

Для каждого результата сохраните контекст: исходный reset, параметры конфигурации, свои изменения, точные ключи и ожидаемую диагностику. Отдельно исследуйте положительный результат, отсутствие данных, конфликт и ожидаемый отказ. Число строк и успешный exit code не заменяют проверки смысла.

Ручные сценарии отказов подробно заданы в [L02](../exercises/l02-access/README.md), [L06](../exercises/l06-revision/README.md), [L11](../exercises/l11-routing/README.md), [L13](../exercises/l13-integration/README.md) и [L14](../exercises/l14-migration/README.md). Прочитайте эталон после попытки, затем повторите решение из чистого исходного состояния. Если собственный вариант отличается, сравните гарантии и границы, а не текст запроса посимвольно.
