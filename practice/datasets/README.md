# Исходные данные ДМ-01

[К практике](../README.md) · [Демонстрационный объект](../../docs/case-study.md) · [Задания](../exercises/README.md)

Пользователь подтвердил состав ДМ-01 2026-11-03. Все данные синтетические; нет реальной геометрии, параметров двигателя, режимов обработки или сертификационных процедур.

| Файл | Содержимое | Использование |
| --- | --- | --- |
| [seed.sql](seed.sql) | Общий воспроизводимый снимок, загружается reset | Все SQL-практикумы |
| [measurements.csv](measurements.csv) | Четыре свойства с неизвестным значением и неверной размерностью | [L04](../exercises/l04-reference/README.md) |
| [options.json](options.json) | Пять полных/частичных конфигураций | [L07](../exercises/l07-options/README.md) |
| [legacy.csv](legacy.csv) | Семь исходных записей миграции | [L14](../exercises/l14-migration/README.md) |

Базовый инженерный состав BASE-01: корень DM-A; по одному HO-A, RO-A, SEN-A, HAR-A, ECU-A; в ECU-A — FW-A. Крепёж по трём ветвям: 6+4+2=12 ea. Запасная позиция датчика o35 входит только при REDUNDANT и не включена в BASE-01. Это достаточная модель семантики вариантов; отдельная выпущенная DUAL-конструкция не создана.

Всего 9 item, 13 revision, 10 occurrence, 9 записей baseline и 9 раскрытых путей. Число совпадающих путей/записей baseline верно только для этой небольшой структуры без повторного использования целого подузла. Обозначение ревизии упорядочивается rev_order, а не строковой сортировкой.

## Намеренные дефекты и ограничения

- [L08](../exercises/l08-requirements/README.md): положительный протокол старой ревизии, pending нового корпуса, документ чужой ревизии и требование без свидетельств.
- [L09](../exercises/l09-change/README.md): согласованное CH-1 ещё имеет pending действие площадки.
- [L10](../exercises/l10-mbom/README.md): o50/e20 покрыто на 1 вместо 2; M-BOLT задана нормой 12, mapping даёт 11.
- [L11](../exercises/l11-routing/README.md): M-FW не распределена; COAT не имеет подтверждённой квалификации.
- [L12](../exercises/l12-physical/README.md): поздняя регистрация замены; нет истории редактирования закрытия старой установки.
- [L13](../exercises/l13-integration/README.md): получатель пуст; outbox — источник ручного воспроизведения, реальный транспорт не развёрнут.

Синтетические номера не кодируют реальные узлы. Даты привязаны к 2026, время фактов трактуется в UTC; при запросах задавайте Z или +00. Границы дат полуоткрытые, серийные границы включены внутри серии DM. Значения NULL имеют явный смысл; отдельного механизма универсального качества данных здесь нет.

Изменения практикумов не следует переносить обратно в seed: иначе исчезнет исходное условие задач. Для нового исследования меняйте данные в транзакции и откатывайте либо применяйте reset.
