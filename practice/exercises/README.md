Перед каждым заданием — reset общей базы, затем работа с заготовкой. Следующее задание не требует успешного выполнения предыдущего, но опирается на его понятия. После попытки запишите результат и причины, откройте эталон, верните исходное состояние и воспроизведите решение. Автоматического оценивания нет.

Порядок: модель → доступ → эксплуатация → НСИ → EBOM → применяемость → опции → требования → изменение → MBOM → маршрут → экземпляры → интеграция → миграция. [ДМ-01 и исходные ограничения](../../docs/case-study.md). [Запуск, сброс и уборка](../environment/README.md).
