# L12. Фактическая история и границы знания

[Каталог заданий](../README.md) · [Глоссарий](../../../references/glossary.md)

## Постановка задачи

При обслуживании DM-100 датчик S-001 заменён на S-002 10 августа, запись I-2 внесена 12 августа. Найдите фактическую конфигурацию и не сделайте выводов, для которых схема не хранит историю.

1. Получите установки на 11 августа 2026 00:00 UTC по всем сегодняшним данным. Интервалы [effective_from,effective_to); отдельная позиция 50 содержит блок управления.
2. Поставлен другой вопрос: «что система знала 11 августа?». Исследуйте recorded_at и хранение effective_to старой записи. Определите, достаточно ли данных для ответа. Не фильтруйте только новые установки и не выдавайте пустую позицию за историческую истину.
3. Найдите экземпляры-кандидаты анализа по LOT-1 через серийные компоненты. Покажите границу: принадлежность партии не доказывает дефект и не даёт количества реально израсходованного материала.
4. Сопоставьте установленное ПО с compatibility для аппаратуры EC-001. Найдите пересечения интервалов разных установок в одной позиции.
5. Предложите на бумаге расширение: неизменяемые события закрытия/коррекции или двухвременная история отношений. Различите фактическое время, время регистрации и основание коррекции; исполняемая двухвременная схема здесь не требуется.

## Предварительные условия

Прочитайте [теорию темы 15](../../../course/15-physical-product-lifecycle/theory.md) и связанные подтемы ниже. Уровень: уверенный SQL. Поднимите [контейнерную среду](../../environment/README.md).

Перед началом выполните `reset`: это возвращает общую исходную базу ДМ-01 и удаляет результаты предыдущего задания в схеме lab. Все практикумы независимы по данным; проходите их в порядке номеров для последовательного освоения. Не выполняйте reset посреди практикума. Файлы в practice/output reset не удаляет.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File practice/environment/lab.ps1 reset
```

Команды в заданиях выполняются из корня репозитория. Для Ubuntu: `bash practice/environment/lab.sh reset`. Редактируйте заготовку на хосте любым редактором; SQL и код исполняйте в контейнерах.

## Критерии самостоятельной оценки

На 11 августа по сегодняшним данным: позиция 30 → S-002, 50 → EC-001. Достоверный ответ «что знала система 11-го» невозможен: нет истории внесения effective_to у I-1. По LOT-1 кандидат DM-100 встречается один раз. EC-001/ECU-A с FW-A совместимы по учебной таблице; пересечений установок нет. Неполный результат обозначен явно.

Сохраните собственный SQL/код, результаты и краткое объяснение оснований решения. Сравнивайте предметный смысл, точные ключи, количества и отказы; порядок строк без ORDER BY и времена выполнения могут отличаться. Автоматического оценивания, баллов и обязательной сдачи нет.
