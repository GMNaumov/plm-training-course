# L14. Python и SQL: перенос с происхождением

[Каталог заданий](../README.md) · [Глоссарий](../../../references/glossary.md)

## Постановка задачи

Перенесите каталог условных объектов из legacy.csv. Источник содержит разные единицы, пропуски, отрицательную и неконечную массу, а также два согласованных обозначения одного изделия. Сохраните происхождение и исключения.

1. Изучите файловую обвязку migrate.py и реализуйте normalize(row). Обозначение — trim+upper; единицы массы только g/kg; значение — конечный положительный Decimal. Не используйте float и не подставляйте ноль при пропуске.
2. Для каждого принятого значения сохраните source_id, нормализованный item_code, mass_kg, rule_version=mass-v1 и original со всеми исходными полями. Отказы запишите с причиной и оригиналом. Входной файл не изменяйте.
3. Загрузите accepted.csv через TEMP-таблицу в одной транзакции. Один source_id не может получить новое содержание при повторе; одинаковый нормализованный код с разными массами — конфликт, а не произвольный выбор. Сохраните mapping каждого принятого source_id на целевой код.
4. Выполните повтор той же загрузки. Затем вручную измените принятое значение S1 в копии CSV, повторите импорт и убедитесь в отказе без частичного эффекта; восстановите файл повторным запуском Python.
5. Сверьте 7 исходных строк как принятые плюс отклонённые, число целевых объектов и соответствий. Объясните согласованное объединение S1/S5. Укажите момент перехода владения данными: здесь источник считается неизменяемым снимком, дельта-перенос не реализован.

## Критерии самостоятельной оценки

Приняты S1, S2, S5: массы 2.5, 1.2, 2.5 kg. Отклонены S3 (неизвестная масса), S4 (единица длины), S6 (отрицательная), S7 (NaN). Итог: 3 исходные принятые строки, 2 целевых изделия, 3 mapping, 4 исключения; 3+4=7. Повтор не меняет числа. Изменённый source_id или конфликтующая масса атомарно отклоняются. Original сохраняет исходные пробелы, число и единицу.

Сохраните собственный SQL/код, результаты и краткое объяснение оснований решения. Сравнивайте предметный смысл, точные ключи, количества и отказы; порядок строк без ORDER BY и времена выполнения могут отличаться. Автоматического оценивания, баллов и обязательной сдачи нет.
