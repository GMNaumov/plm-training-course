# L10. Сверка EBOM и MBOM по путям

[Каталог заданий](../README.md) · [Глоссарий](../../../references/glossary.md)

## Постановка задачи

Для площадки P1 подготовлена производственная ведомость по BASE-01. Структуры организованы по-разному, а крепёж сведён в одну строку. Найдите необъяснимое расхождение, сохранив производственные дополнения.

1. Используйте готовый lab.base_tree как входной снимок. Для каждого пути суммируйте mapping и сравните с ожидаемым количеством; сохраните отсутствующие и лишние пути через FULL JOIN.
2. Проверьте, что mapping указывает на ту же ревизию и единицу, нужную площадку P1 и исходную BASE-01. Одного совпадения обозначений недостаточно.
3. Независимо сверните mapping по mline и сопоставьте с количеством продуктовой строки. Эта проверка должна обнаруживать как нехватку, так и избыток. Производственные расходники обрабатываются отдельно.
4. Исправьте только ошибочное покрытие o50/e20. Обоснуйте наличие M-SEAL и отсутствие инженерного пути для него. Не добавляйте расходник в поставляемую EBOM ради совпадения отчётов.
5. Объясните, почему контроль одновременно родительской сборки и её дочерних позиций не означает расход двух изделий: это разные уровни представления, а правило материального планирования должно указать самостоятельно выпускаемые узлы, фантомы и детали.

## Предварительные условия

Прочитайте [теорию темы 13](../../../course/13-manufacturing-bom/theory.md) и связанные подтемы ниже. Уровень: уверенный SQL. Поднимите [контейнерную среду](../../environment/README.md).

Перед началом выполните `reset`: это возвращает общую исходную базу ДМ-01 и удаляет результаты предыдущего задания в схеме lab. Все практикумы независимы по данным; проходите их в порядке номеров для последовательного освоения. Не выполняйте reset посреди практикума. Файлы в practice/output reset не удаляет.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File practice/environment/lab.ps1 reset
```

Команды в заданиях выполняются из корня репозитория. Для Ubuntu: `bash practice/environment/lab.sh reset`. Редактируйте заготовку на хосте любым редактором; SQL и код исполняйте в контейнерах.

## Критерии самостоятельной оценки

Исходно o50/e20 покрыт на 1 вместо 2; сумма mapping для M-BOLT равна 11 вместо 12. После исправления все 9 инженерных путей покрыты, продуктовые количества согласованы, несовпадений ревизии/единицы/контекста нет. M-SEAL остаётся 0.05 kg с производственным основанием. Он не считается лишним инженерным компонентом.

Сохраните собственный SQL/код, результаты и краткое объяснение оснований решения. Сравнивайте предметный смысл, точные ключи, количества и отказы; порядок строк без ORDER BY и времена выполнения могут отличаться. Автоматического оценивания, баллов и обязательной сдачи нет.
