# L09. Изменение: согласовано и внедрено

[Каталог заданий](../README.md) · [Глоссарий](../../../references/glossary.md)

## Постановка задачи

CH-1 переводит корпус с HO-A на HO-B. Решение согласовано, инженерная часть завершена, действие площадки P1 ещё pending. Обслуживание DM-100 исключено с сохранённым основанием.

1. Выведите действия, их область и основания. Отдельно сформулируйте, почему state=approved не означает implemented.
2. Реализуйте закрытие с предикатами: ожидаемая lock_version=0, исходный approved, отсутствие pending. В одной транзакции блокируйте change_order, проверяйте/изменяйте действия и переходите к implemented. До закрытия ACT-2 ожидается ноль изменённых строк.
3. По условному подтверждению DEC-P1-01 завершите ACT-2 с сохранением основания. ACT-3 оставьте excluded, не превращая исключение в done.
4. Повторите переход со старой версией. Объясните результат UPDATE 0 и различие конфликта версии, отсутствия объекта и невыполненных предусловий.
5. Для двух сессий psql обсудите порядок захвата родительской блокировки. Любой код, меняющий действия, обязан сначала блокировать CH-1; иначе локально корректный запрос не гарантирует сквозную готовность. Не меняйте физическую историю DM-100 вслед за типовым выпуском.

## Предварительные условия

Прочитайте [теорию темы 12](../../../course/12-change-and-workflow/theory.md) и связанные подтемы ниже. Уровень: уверенный SQL. Поднимите [контейнерную среду](../../environment/README.md).

Перед началом выполните `reset`: это возвращает общую исходную базу ДМ-01 и удаляет результаты предыдущего задания в схеме lab. Все практикумы независимы по данным; проходите их в порядке номеров для последовательного освоения. Не выполняйте reset посреди практикума. Файлы в practice/output reset не удаляет.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File practice/environment/lab.ps1 reset
```

Команды в заданиях выполняются из корня репозитория. Для Ubuntu: `bash practice/environment/lab.sh reset`. Редактируйте заготовку на хосте любым редактором; SQL и код исполняйте в контейнерах.

## Критерии самостоятельной оценки

До подтверждения P1 переход меняет 0 строк; после — одну. Итог CH-1: implemented, lock_version=1. Повтор с версией 0 меняет 0 строк. ACT-3 остаётся excluded с основанием. Никакие установки, BASE-01 и старые свидетельства не переписаны. В отчёте назван общий протокол блокировки родителя для всех писателей действий.

Сохраните собственный SQL/код, результаты и краткое объяснение оснований решения. Сравнивайте предметный смысл, точные ключи, количества и отказы; порядок строк без ORDER BY и времена выполнения могут отличаться. Автоматического оценивания, баллов и обязательной сдачи нет.
