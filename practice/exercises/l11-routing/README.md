# L11. Маршрут, распределение и готовность ресурсов

[Каталог заданий](../README.md) · [Глоссарий](../../../references/glossary.md)

## Постановка задачи

Проверьте маршрут ROUTE-A для ДМ-01: получение заготовки, мехобработка, термообработка, покрытие, сборка, электромонтаж и контроль/испытания. Последовательность является условной учебной моделью управления данными, а не реальной технологией изготовления.

1. Сравните количества каждой mline с суммой allocation. Не теряйте строки без распределения; включите программный выпуск и расходник.
2. Проверьте соответствие family операции и ресурса, а также qualified. Назовите решение, которое блокирует готовность маршрута, даже если все количества распределены.
3. Напишите рекурсивный обход precedence с фиксацией пути и диагностикой циклов. Найдите начальные операции; не объявляйте сортировку по OP10…OP70 доказательством корректного графа.
4. Распределите M-FW на OP60 как загрузку ПО. Не отмечайте COAT квалифицированным без основания. Составьте короткое решение «готов/не готов» с раздельными выводами о полноте allocation, ацикличности и ресурсах.
5. В откатываемой транзакции добавьте OP70→OP20 и проверьте цикл. Объясните разницу между этой связью, вхождением BOM и согласованием маршрута. Производственные режимы, фактические времена и критерии испытаний выдумывать не требуется.

Перед началом выполните `reset`: это возвращает общую исходную базу ДМ-01 и удаляет результаты предыдущего задания в схеме lab. Все практикумы независимы по данным; проходите их в порядке номеров для последовательного освоения. Не выполняйте reset посреди практикума. Файлы в practice/output reset не удаляет.

```powershell

```

Команды в заданиях выполняются из корня репозитория. Для Ubuntu: `bash practice/environment/lab.sh reset`. Редактируйте заготовку на хосте любым редактором; SQL и код исполняйте в контейнерах.

## Критерии самостоятельной оценки

До исправления только M-FW не распределена: ожидается 1, фактически 0. После добавления allocation количества согласованы. OP40 использует COAT с qualified=false, поэтому маршрут не готов к разрешению применения. В исходном precedence циклов нет, старт OP10, финиш OP70. Искусственный цикл обнаружен и отменён.

Сохраните собственный SQL/код, результаты и краткое объяснение оснований решения. Сравнивайте предметный смысл, точные ключи, количества и отказы; порядок строк без ORDER BY и времена выполнения могут отличаться. Автоматического оценивания, баллов и обязательной сдачи нет.
