# L05. Раскрытие EBOM без потери путей

[Каталог заданий](../README.md) · [Глоссарий](../../../references/glossary.md)

## Постановка задачи

Для базового исполнения ДМ-01 составьте структурную ведомость и сводную потребность крепежа. Работайте с BASE-01, где выбор точных ревизий уже сохранён. Опциональное o35 в эту конфигурацию не входит.

1. Напишите рекурсивный CTE от DM-A, соединяя occurrence с baseline по occurrence_id и имени BASE-01. Сохраняйте полный путь идентификаторов вхождений и выбранную ревизию. Не выбирайте последнюю ревизию заново.
2. На каждом шаге умножайте количества. Не удаляйте одинаковые ревизии, встречающиеся по разным путям. Результат сгруппируйте по точной ревизии и единице только после обхода.
3. Добавьте массив посещённых ревизий на пути и признак cycle; остановите дальнейшее раскрытие циклической ветви. Объясните отличие цикла от законного использования BOLT-A в трёх ветвях.
4. Получите прямые where-used для BOLT и объясните, чем они отличаются от всех путей до DM-A. Для ручного исследования цикла используйте транзакцию: добавьте BOLT-A → DM и соответствующую строку BASE-01, выполните обход, затем ROLLBACK.
5. Только после собственной реализации сравните результат с готовым lab.base_tree, используемым следующими практикумами.

## Предварительные условия

Прочитайте [теорию темы 08](../../../course/08-engineering-bom/theory.md) и связанные подтемы ниже. Уровень: уверенный SQL. Поднимите [контейнерную среду](../../environment/README.md).

Перед началом выполните `reset`: это возвращает общую исходную базу ДМ-01 и удаляет результаты предыдущего задания в схеме lab. Все практикумы независимы по данным; проходите их в порядке номеров для последовательного освоения. Не выполняйте reset посреди практикума. Файлы в practice/output reset не удаляет.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File practice/environment/lab.ps1 reset
```

Команды в заданиях выполняются из корня репозитория. Для Ubuntu: `bash practice/environment/lab.sh reset`. Редактируйте заготовку на хосте любым редактором; SQL и код исполняйте в контейнерах.

## Критерии самостоятельной оценки

В BASE-01 раскрыто 9 путей, циклов нет. BOLT-A встречается по o10/h10, o20/r10, o50/e20 с количествами 6, 4, 2; общий итог 12 ea. FW-A сохранена как программный элемент. Прямых применений BOLT три: HO-A, RO-A, ECU-A. Опциональный второй датчик не попал в BASE. Опыт с циклом завершается диагностикой, а транзакция отменена.

Сохраните собственный SQL/код, результаты и краткое объяснение оснований решения. Сравнивайте предметный смысл, точные ключи, количества и отказы; порядок строк без ORDER BY и времена выполнения могут отличаться. Автоматического оценивания, баллов и обязательной сдачи нет.
