# L06. Применяемость и объяснимый выбор ревизии

[Каталог заданий](../README.md) · [Глоссарий](../../../references/glossary.md)

## Постановка задачи

Разрешите плавающую ссылку на корпус и датчик для заданных контекстов. В отличие от L05, здесь выбирается определение по правилам. Сохранённую BASE-01 не переписывайте.

1. Задайте контексты HO на 30 июня и 1 июля 2026 для DM-100 и DM-101; SEN на эти две даты для DM-100; HO для чужой серии OTHER. Учитывайте released, полуоткрытые даты [from,to) и включённые серийные границы.
2. Отделите фильтрацию от приоритета priority DESC, rev_order DESC. Не используйте LIMIT 1 как способ скрыть равноприоритетных кандидатов. Покажите OK/MISSING/AMBIGUOUS и выбранные определения по каждому входу, в том числе при нуле кандидатов.
3. В отдельной откатываемой транзакции сделайте HO-B применимой к DM-100 и равной HO-A по priority/rev_order. Убедитесь, что запрос сообщает неоднозначность. Изменение порядка чтения не должно менять вывод.
4. Сохраните выбор HO-B для o10 в новой базовой линии HO-101 с полным контекстом и версией правила. Явно обозначьте, что она фиксирует только одно вхождение, а не весь модуль.
5. Объясните, почему последующий запрет применения не должен стирать ранее принятую BASE-01 и почему историческое воспроизведение не разрешает новое изготовление автоматически.

## Предварительные условия

Прочитайте [теорию темы 09](../../../course/09-revision-configuration/theory.md) и связанные подтемы ниже. Уровень: уверенный SQL. Поднимите [контейнерную среду](../../environment/README.md).

Перед началом выполните `reset`: это возвращает общую исходную базу ДМ-01 и удаляет результаты предыдущего задания в схеме lab. Все практикумы независимы по данным; проходите их в порядке номеров для последовательного освоения. Не выполняйте reset посреди практикума. Файлы в practice/output reset не удаляет.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File practice/environment/lab.ps1 reset
```

Команды в заданиях выполняются из корня репозитория. Для Ubuntu: `bash practice/environment/lab.sh reset`. Редактируйте заготовку на хосте любым редактором; SQL и код исполняйте в контейнерах.

[SQL-заготовка L06](../../postgresql/queries/l06.sql). Выполните после заполнения:

## Критерии самостоятельной оценки

Для HO: 30.06/100 → HO-A, 01.07/100 → HO-A, 01.07/101 → HO-B, 30.06/101 → MISSING. Для SEN: 30.06 → SEN-A, 01.07 → SEN-B. OTHER → MISSING. HO-C не выбрана из-за draft. Искусственное равенство даёт AMBIGUOUS. BASE-01 осталась прежней; HO-101 явно неполная.

Сохраните собственный SQL/код, результаты и краткое объяснение оснований решения. Сравнивайте предметный смысл, точные ключи, количества и отказы; порядок строк без ORDER BY и времена выполнения могут отличаться. Автоматического оценивания, баллов и обязательной сдачи нет.
