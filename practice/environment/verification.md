## Дополнительный прогон Java J01–J12, 2026-11-03

Использован отдельный Compose-проект `plm-java-review`, прежние digest образов и SHA-256 pgJDBC. Фактическая среда — Windows 11, Docker Desktop 4.96.3, Engine 29.9.2, Compose 5.6.1, linux/amd64; PowerShell 5.1 и Ubuntu WSL. Новые библиотеки, локальные JDK/PostgreSQL и внешние сервисы не добавлялись.

Все 12 эталонных классов, все 12 заготовок и обе копии инфраструктуры Lab скомпилированы JDK контейнера. Source-file запуск с автоматической компиляцией соседних Lab/OrderedConsumer проверен отдельно, в том числе OutboxWorker. Временная авторская программа выполнила 81 проверку нормальных, граничных, отказных и конкурентных сценариев; отдельный завершающий прогон — ещё 5 проверок неверных CLI-флагов и пустого id снимка. Первый конкурентный прогон выявил deadlock усиления блокировки change_order после INSERT команды с FK. Исправлено использованием FOR NO KEY UPDATE, совместимого с KEY SHARE. Повторный и дополненный прогоны завершились успешно; причина и границы общего протокола писателей включены в J05.

Обновлённый общий reset проверен с независимым исполнением прежних SQL-эталонов L01–L13 с ON_ERROR_STOP. L14 и прежние Python-сценарии в этом дополнительном прогоне не перезапускались; их код не менялся. Исходные 9/13/9 и один outbox L13 сохранены, новые события находятся в отдельной java_outbox. Новое Java-задание реально запущено через Windows PowerShell lab.ps1 и через Ubuntu WSL lab.sh; Bash-синтаксис проверен. Архитектура ARM, сеть, коммерческие PLM и промышленная нагрузка не проверялись.

Редакционная проверка: 238 Markdown, 1706 относительных ссылок, включая 147 якорей; ошибок нет. Сохранены 21 тема и 92 подтемы. Добавлены прямые переходы из десяти practice.md, обновлены оглавления, формат, результаты, глоссарий и статус предложений. Git diff --check пройден. LICENSE, digest, Dockerfile, обёртки, исходные model.sql/seed.sql, Python и прежние Java/SQL-эталоны не менялись; в reset добавлено одно включение новых таблиц в общую транзакцию.

Проверочный проект, его сеть, том и Java-образ удалены. Загруженный PostgreSQL-образ и адресно выбранные записи нового build cache удалены; глобальная очистка не применялась. Временные авторские программы, классы, журналы и выгрузки удалены, в output сохранён только .gitkeep. Рабочая БД после проверки намеренно не оставлена; первый запуск обучающегося снова загрузит закреплённые зависимости.

## Проверка структуры, ссылок и языка исходников, 2026-11-03

Проверена текущая структура: 21 основная тема с README.md, theory.md и practice.md; 92 вложенные подтемы с README.md; 26 каталогов заданий с постановками и отдельными Markdown-эталонами. Все 238 Markdown-файлов достижимы по навигации от главного README.md. Переносить или переименовывать каталоги не потребовалось.

Проверены 1706 относительных ссылок, включая 147 переходов к якорям: отсутствующих файлов, неверных якорей, выходов за корень проекта и недостижимых Markdown нет. Для 53 уникальных внешних URL проверены корректность адреса и доступность страницы: 36 ответили HTTP 200 при прямом запросе; остальные 17 проверены через веб-инструмент после сетевых тайм-аутов, ошибки DNS либо HTTP 403. Подтверждённых удалённых страниц не обнаружено, замены адресов не потребовались. Успешное открытие страницы не означает доступа ко всему содержимому защищённой справки 3DEXPERIENCE; прежние ограничения источников сохраняются. Внешние HTML-якоря отдельно не валидировались.

На русский переведены подсказки запуска и сообщения незавершённых методов Java, свободный текст служебных записей, оставшиеся пояснения и комментарии, сообщения PowerShell, итоговая строка Python-переноса, текст исключений SQL L14 и синтетические текстовые файлы J11. Обновлены совпадающие формулировки в эталоне L14 и инструкции запуска. Идентификаторы, API, машинные коды результатов и ошибок, поля CSV/JSON/TSV и служебные параметры сохранены как элементы контрактов.
