# J09. Разбор двух инвариантов установки

[К заданию](../exercises/j09-java-installation/README.md) · [К эталонам](README.md) · [Исходник](java/InstallationService.java)

После reset и j09-serials.sql используйте команды задания с путём `practice/solutions/java/InstallationService.java`. Первая установка успешна, повторное занятие позиции и повторное занятие ребёнка отвергаются. На точной границе завершения I-1 S-001 можно установить в другой родитель.

Сервис блокирует serial_unit родителя и ребёнка в порядке id. Родитель защищает область `(parent, position)`, ребёнок — область его применения во всех родителях. Блокировка только существующих installation не помогла бы, когда первая запись ещё отсутствует. SERIALIZABLE и exclusion constraints могут дать другие модели защиты, но здесь сознательно выбран объяснимый протокол строковых блокировок.

После ожидания блокировки новый statement READ COMMITTED проверяет уже актуальные записи. Условие пересечения содержит OR двух предметных областей и `tstzrange(...,'[)') && ...`. Полуоткрытая граница разрешает непосредственную передачу между интервалами. NULL верхней границы означает неограниченный интервал, а не пропущенную проверку.

Параллельные вызовы для двух детей одной позиции дают один успех. Для одного ребёнка в разных родителях — тоже один успех. Упорядочение блокировок уменьшает риск deadlock протокола; тайм-ауты по-прежнему возможны при посторонних писателях. После ошибки смотрите отдельным соединением, что лишняя установка не появилась.

Ограничение assembly→part делает граф одноуровневым и исключает циклы по типам. Это не универсальный сервис всей иерархии изделия. Применяемость, разрешение замены, совместимость аппаратуры/ПО и права пользователя остаются за границей. Прямые INSERT вне протокола способны нарушить оба инварианта, потому что исходная installation L12 не имеет exclusion constraints.

Исторические строки не удаляются. Новый успешный INSERT не исправляет прошлое знание и не делает recorded_at двухвременной историей. Разделение этих задач продолжает J10.
