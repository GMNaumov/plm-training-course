# Эталон L11. Маршрут, распределение и готовность ресурсов

[Постановка, условия и самопроверка](../exercises/l11-routing/README.md) · [Все эталоны](README.md)

## Решение и основания

Распределение определяет, где используется строка производственного определения. Оно не утверждает фактическое потребление или успешную загрузку ПО. Квалификация ресурса — отдельный управляемый факт, и её отсутствие нельзя исправить одной удобной записью без подтверждения.

Рекурсивный обход останавливает ветвь при повторе узла. Для общего маршрута следует также проверять связность, области маршрутов, необходимые контрольные точки и допустимость параллельности. Семь операций покрывают семейства процессов на уровне управления; они не задают реальных рецептур, режимов или норм сертификации.

## Ожидаемый результат

До исправления только M-FW не распределена: ожидается 1, фактически 0. После добавления allocation количества согласованы. OP40 использует COAT с qualified=false, поэтому маршрут не готов к разрешению применения. В исходном precedence циклов нет, старт OP10, финиш OP70. Искусственный цикл обнаружен и отменён.

## Воспроизведение

[Эталонный SQL](l11.sql)

Сначала верните исходные данные действием reset. Затем выполните SQL командой `sql practice/solutions/l11.sql` через lab.ps1 или lab.sh по инструкции задания. SQL содержит демонстрацию успешных операций; ожидаемые отказы изучаются отдельно, чтобы не прерывать файл при ON_ERROR_STOP. Точная последовательность и параметры приведены в постановке.

Это одно обоснованное решение. Иная схема или запрос допустимы при сохранении предметных инвариантов и диагностик. Эталон не является промышленным модулем коммерческой PLM-системы.

## Ручной цикл маршрута

После reset начните `BEGIN; INSERT INTO lab.precedence VALUES ('OP70','OP20');`. Затем выполните рекурсивный SELECT p из SQL-эталона в этой же сессии: он вернёт строки с cycle=true. Не выполняйте весь файл эталона повторно после добавления M-FW — повторная вставка allocation нарушит ключ. Завершите опыт ROLLBACK.

Для итогового решения отдельно повторите агрегирование allocation после добавления M-FW. Пустой список расхождений означает полноту количеств; OP40 с COAT=false всё ещё блокирует готовность маршрута.
