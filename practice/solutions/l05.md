# Эталон L05. Раскрытие EBOM без потери путей

[Постановка, условия и самопроверка](../exercises/l05-ebom/README.md) · [Все эталоны](README.md)

## Решение и основания

Ключ промежуточного результата — путь вхождений. DISTINCT по revision_id до суммирования потерял бы часть потребности. UNION ALL сохраняет вклады каждого пути, а массив посещений ограничивает именно текущую ветвь.

Готовый base_tree ограничен одной учебной базовой линией и не является универсальным конфигуратором. В нём нет вычисления опций и проверки полноты произвольного разрешения. При обнаружении цикла инженерный итог нужно признать недостоверным; просто исключить циклическую строку и выдать остаток как полный состав нельзя. Пустой набор без проверки контекста и прав не доказывает отсутствие состава.

## Ожидаемый результат

В BASE-01 раскрыто 9 путей, циклов нет. BOLT-A встречается по o10/h10, o20/r10, o50/e20 с количествами 6, 4, 2; общий итог 12 ea. FW-A сохранена как программный элемент. Прямых применений BOLT три: HO-A, RO-A, ECU-A. Опциональный второй датчик не попал в BASE. Опыт с циклом завершается диагностикой, а транзакция отменена.

## Ручное исследование цикла

После reset выполните в одной интерактивной сессии:

```sql
BEGIN;
INSERT INTO lab.occurrence VALUES
 ('cycle','BOLT-A','99','DM','DM-A',1,'ea',NULL);
INSERT INTO lab.baseline VALUES
 ('BASE-01','cycle','DM-A','{"scope":"cycle experiment"}');
SELECT path,revision_id,cycle FROM lab.base_tree WHERE cycle ORDER BY path;
ROLLBACK;
```

Циклические пути: o10/h10/cycle, o20/r10/cycle, o50/e20/cycle; все возвращаются в DM-A. Для собственной реализации выполните её SELECT в той же транзакции вместо чтения готового представления. После ROLLBACK исходная конфигурация восстановлена.
