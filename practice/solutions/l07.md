# Эталон L07. Ограничения опций на Python

[Постановка, условия и самопроверка](../exercises/l07-options/README.md) · [Все эталоны](README.md)

## Решение и основания

Функция сначала валидирует домены полей, затем проверяет применимые импликации для известных значений. Нельзя проверять импликацию через обычную истинность строки или считать неизвестный выбор отрицательным.

Эталон имеет только стандартную библиотеку Python. Он проверяет локальную модель опций и не обращается к текущему состоянию БД: это намеренное разделение уровней. Статус VALID относится только к логической модели. Дальнейший конфигуратор обязан сопоставить выбранные признаки с существующими определениями и правилами L06, а затем с допусками аппаратуры и ПО.

## Ожидаемый результат

Статусы C1…C5: VALID, INVALID, VALID, INCOMPLETE, INVALID. C2 нарушает REDUNDANT→DUAL, C5 — DUAL→FW-B. Базовое исполнение имеет один датчик, резервированное — два. Неизвестные значения не проходят как допустимые. Отдельно описаны логическая допустимость, наличие конструкции, разрешённая ревизия и подтверждённая совместимость.

## Воспроизведение

[Эталонный SQL](l07.sql) · [Эталон Python](options.py)

Сначала верните исходные данные действием reset. Затем выполните SQL командой `sql practice/solutions/l07.sql` через lab.ps1 или lab.sh по инструкции задания. SQL содержит демонстрацию успешных операций; ожидаемые отказы изучаются отдельно, чтобы не прерывать файл при ON_ERROR_STOP. Основной результат получите запуском practice/solutions/options.py; SQL показывает опциональную позицию. Точная последовательность и параметры приведены в постановке.

Это одно обоснованное решение. Иная схема или запрос допустимы при сохранении предметных инвариантов и диагностик. Эталон не является промышленным модулем коммерческой PLM-системы.

## Ручные дополнительные входы

Временно добавьте в копию JSON конфигурации с пропущенной firmware, redundant="false" и redundant=true/controller=SINGLE/firmware=null. Ожидаются соответственно INCOMPLETE, INVALID и INVALID. В третьем случае неполнота не отменяет уже известного противоречия. Сравнивайте список причин по смыслу. При редактировании исходного JSON после опыта восстановите исходные пять строк, чтобы эталон оставался воспроизводимым.
