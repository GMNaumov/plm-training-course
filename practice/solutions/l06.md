# Эталон L06. Применяемость и объяснимый выбор ревизии

[Постановка, условия и самопроверка](../exercises/l06-revision/README.md) · [Все эталоны](README.md)

## Решение и основания

LEFT JOIN начинается с набора контекстов, поэтому отсутствие кандидата сохраняется в результате. DENSE_RANK ранжирует допущенные определения; затем считаются все кандидаты первого ранга. Нулевая, единственная и множественная вершина ранга имеют разные предметные значения.

Серийный номер сравнивается как число внутри серии DM. Открытая верхняя граница выражена NULL и проверяется явно. Выбор по двум измерениям требует одновременного выполнения условий. Базовая линия хранит точную ревизию и контекст; изменение справочных правил не должно незаметно пересчитать исторический выбор.

## Ожидаемый результат

Для HO: 30.06/100 → HO-A, 01.07/100 → HO-A, 01.07/101 → HO-B, 30.06/101 → MISSING. Для SEN: 30.06 → SEN-A, 01.07 → SEN-B. OTHER → MISSING. HO-C не выбрана из-за draft. Искусственное равенство даёт AMBIGUOUS. BASE-01 осталась прежней; HO-101 явно неполная.

## Ручная неоднозначность

После reset в интерактивной сессии:

```sql
BEGIN;
UPDATE lab.revision SET serial_from=100,rev_order=1 WHERE id='HO-B';
WITH admitted AS (
 SELECT id,dense_rank() OVER(ORDER BY priority DESC,rev_order DESC) AS rank
 FROM lab.revision
 WHERE item_id='HO' AND state='released'
 AND DATE '2026-07-01'>=valid_from
 AND (valid_to IS NULL OR DATE '2026-07-01'<valid_to)
 AND series='DM' AND 100>=serial_from AND (serial_to IS NULL OR 100<=serial_to)
)
SELECT CASE count(*) WHEN 0 THEN 'MISSING' WHEN 1 THEN 'OK' ELSE 'AMBIGUOUS' END,
       string_agg(id,',' ORDER BY id)
FROM admitted WHERE rank=1;
ROLLBACK;
```

Ожидается AMBIGUOUS, HO-A,HO-B. HO-C остаётся draft. Изменение синтетических приоритетов служит только исследованию диагностики.

## Граница сохранённого выбора

Точная выбранная ревизия не замораживает атрибуты самого вхождения и все файлы. В таблице baseline также нет проверки принадлежности revision_id дочернему изделию: исходные строки согласованы подготовленным набором. HO-101 является частичным сохранённым выбором с явной областью, а не принятым комплектом всего ДМ-01. [Предложение P01](../../docs/practice-expansion-proposals.md#p01) отделяет эти гарантии.
