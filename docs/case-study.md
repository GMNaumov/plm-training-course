# Демонстрационное изделие ДМ-01

[К документам](README.md) · [Исходные данные](../practice/datasets/README.md) · [Практикумы](../practice/exercises/README.md)

Пользователь подтвердил 2026-11-03 вымышленный демонстрационный модуль авиационного двигателя ДМ-01: корпус, роторный узел, датчики, жгут, электронный блок управления и прошивка. Исполнения — базовое и с резервированием датчиков. Конкретные синтетические идентификаторы, количества и даты выбраны для обучения; они не описывают реальное изделие.

| Область | Учебное представление |
| --- | --- |
| Механика | Корпус HO, роторный узел RO, крепёж BOLT |
| Электрика/электроника | Датчик SEN, жгут HAR, блок ECU |
| ПО | Ревизии FW-A/FW-B, совместимость с ECU-A |
| Производство | Площадка P1, расходник SEAL, ROUTE-A |
| Факт | DM-100, два серийных датчика, серийный блок и LOT-1 |

Базовый состав имеет один датчик, резервированное исполнение включает дополнительное вхождение o35. Полностью выпущенная аппаратная DUAL-конструкция не подготовлена: это осознанное условие L07, где логическая допустимость отличается от готовности изготовления. Базовая линия BASE-01 фиксирует точные определения на условную дату 2026-06-01, серия DM, номер 100.

Производственная часть охватывает получение заготовки, мехобработку, термообработку, покрытие, сборку, электромонтаж/загрузку ПО, контроль и испытания. Маршрут — учебная последовательность управления определениями. Реальные режимы, допуски, рецептуры, геометрия CAD и результаты испытаний не поставляются.

Модель физических экземпляров ограничена несколькими установками и загрузкой ПО; полнота as-built всего модуля не заявляется. Связь партии с компонентом показывает отбор популяции, а не полный материальный баланс. История регистрационного времени отношений в исходной installation намеренно неполная для разбора L12. Дополнительный J10 использует отдельную java_fact с двумя временными осями; это подготовленная синтетическая история, а не восстановление утраченных сведений исходной таблицы.

В теории прежние отдельные иллюстрации остаются условными разборами; их количества и обозначения не обязаны совпадать с данными ДМ-01. Практические источники истины — seed.sql и явный контекст задания. Нормы сертификации, юрисдикция и обязательные процедуры не выбирались; учебные решения не следует выдавать за авиационные требования.
