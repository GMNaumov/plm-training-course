# Подготовка обучающегося и компьютера

[К документам](README.md) · [Контейнерная среда и команды](../practice/environment/README.md) · [Задания](../practice/exercises/README.md)

Аудитория уверенно программирует и пишет SQL, но может не знать PLM/PDM. Нужны понимание ключей, JOIN, GROUP BY и транзакций; рекурсивный CTE разбирается через состав. Для разработки Python — функции, исключения, JSON/CSV и Decimal; для Java — классы, JDBC и границы транзакции. Незнакомые термины объясняет [глоссарий](../references/glossary.md).

На компьютере требуются Docker с Compose v2+, редактор и место для репозитория/тома. Windows 11 + Docker Desktop + WSL 2/Ubuntu поддержаны инструкциями; Bash-сценарий также подходит для Linux с Docker Engine. Первичная загрузка образов и JDBC требует сети. Локальные JDK, Python и PostgreSQL не нужны: вся исполняемая среда находится в контейнерах. Лицензию и возможность запуска Docker Desktop определяет владелец рабочей станции.

Версии зафиксированы и проверены в контейнерах: PostgreSQL 18.6, Python 3.15.2, Temurin 25.0.5 LTS, JDBC 42.7.14. Данные предназначены только для отдельного учебного стенда. Подключение к существующим промышленным БД не требуется. Инструкция среды описывает запуск, диагностику, сброс и очистку.

Программные аналогии помогают, но ревизия не равна автоматически коммиту, BOM — дереву каталогов, а выпуск — развёртыванию программы. Практика закрепляет предметные различия и не обучает всем интерфейсам коммерческих PLM.
