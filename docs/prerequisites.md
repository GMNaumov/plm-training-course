# Входные знания и подготовка среды

[К разделу](README.md)

## Что требуется для чтения

Курс предполагает опыт программирования и SQL: понимание сущностей, ключей, связей, условий выборки и транзакций на базовом уровне. Предварительный опыт PLM/PDM, знание интерфейсов конкретных систем и авиационных стандартов не требуются. Английские термины объясняются по-русски в [глоссарии](../references/glossary.md).

Программные аналогии помогают понять идентичность и зависимости, но инженерная ревизия не равна автоматически коммиту, BOM — дереву каталогов, а выпуск — развёртыванию программы. У этих механизмов свои предметные правила.

## Техническая среда

Для текущей теории достаточно средства чтения Markdown с относительными ссылками. Пользователь сообщил о наличии JVM, Python и PostgreSQL, однако версии, способ запуска, доступность сервера и параметры подключения ещё не проверены.

Перед разработкой практики нужно определить доступные версии, локальный или иной способ запуска БД, возможность создания отдельной учебной базы и ограничения установки компонентов. Сейчас эти решения не приняты; команды установки, зависимости и подключения не назначены.

## Роль технологий

PostgreSQL предполагается для представления предметных данных и SQL, Python — для автоматизации и анализа, Java — для сервисной логики и адаптеров. Это предварительное распределение. Учебная модель будет самостоятельной моделью предметной области; она не воспроизводит внутренние таблицы коммерческой PLM-системы.
