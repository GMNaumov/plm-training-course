# Углублённый курс PLM/PDM

Технологически нейтральный курс для специалистов, умеющих программировать и писать SQL-запросы, без предварительного опыта PLM/PDM.

Ориентир — 2–3 недели последовательного самостоятельного обучения «с нуля до уверенного пользователя». После вводных основ идут администрирование, внедрение и моделирование процессов, затем разработка и интеграции. Сквозная предметная область — сложные многокомпонентные изделия авиа- и двигателестроения с механическими, электрическими и электронными подсистемами и развитой вариативностью.

В проекте развёрнут учебный контент всех 21 тем и 92 вложенных подтем: предметные модели, правила работы, подробные объяснения механизмов, выбор решений, пограничные случаи и условные разборы. Материал связывает инженерные определения с производством, физическими экземплярами и интеграциями. [Глоссарий](references/glossary.md) содержит определения терминов и расшифровки сокращений; [источники](references/sources.md) фиксируют использованные первичные материалы.

Добавлены [14 практикумов](practice/exercises/README.md), прямо покрывающих 14 из 21 темы (66,7%): постановки, предварительные условия, заготовки SQL/Python/Java, синтетические данные ДМ-01, критерии самостоятельной оценки и [эталонные решения](practice/solutions/README.md). Вся исполняемая среда находится в Docker; [инструкция запуска, сброса и очистки](practice/environment/README.md). Автоматического оценивания нет. Продолжительность 2–3 недели остаётся ориентиром, обязательная часовая нагрузка не назначена.
